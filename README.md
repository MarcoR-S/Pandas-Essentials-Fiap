Este repositório contém uma série de exercícios práticos para o domínio da biblioteca **Pandas** em Python. Os exercícios cobrem desde a criação de DataFrames até operações avançadas de agrupamento e médias móveis.

## 🚀 Tecnologias Utilizadas
*   Python 3.x
*   Pandas
*   NumPy

## 📋 Estrutura dos Exercícios

O arquivo principal contém as seguintes implementações:

*   **Ex 1 (Joins):** Demonstração de união de tabelas baseada em índices (`join`).
*   **Ex 2 (Merges):** Cruzamento de dados entre tabelas de Produtos e Vendas (`merge`) com cálculos de colunas.
*   **Ex 3 (Data Cleaning):** Tratamento de valores ausentes utilizando `dropna` para remoção e `fillna` para inputação com média.
*   **Ex 4 (Slicing & Loc):** Navegação e seleção de dados usando indexadores `loc` (rótulos) e `iloc` (posições).
*   **Ex 5 (Filtros Booleanos):** Seleção condicional complexa usando operadores lógicos `&` (E) e `|` (OU).
*   **Ex 6 (Ordenação):** Organização de dados hierárquica por múltiplas colunas e diferentes direções (ASC/DESC).
*   **Ex 7 (Séries Temporais):** Criação de intervalos de datas e cálculo de **Média Móvel** com a função `rolling`.
*   **Ex 8 (Agrupamentos):** Agregação de dados com `groupby` para gerar resumos financeiros por categoria.
